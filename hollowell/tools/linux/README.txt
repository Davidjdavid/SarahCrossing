HOLLOWELL: the 12 November 2026 version
=======================================

This folder is the whole game, kept exactly as it was on 12 November 2026. It works without
the internet.

To play
-------
- Run ./play-hollowell.sh (or double-click it and choose Run). It opens the game in a window
  of its own. With Chromium or Chrome installed, this version keeps its saves to itself.
- Or just open Hollowell.html in any web browser.
- To put it in your applications menu, run ./add-to-menu.sh once.

Click the game once so the keyboard reaches it. The controls are listed beside the game, and
can be changed in the game's own menu (Options, then Controls). A controller works too.

Saves
-----
The game saves as you go, and from its menu, in three slots kept in the browser. The Save code
button above the game turns your place into a line of text: copy it to keep a save safe, or
paste it into another copy of the game (a newer version, or the online page) to carry on there.
